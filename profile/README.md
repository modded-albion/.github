# Modded Albion

Mods and tools for [Masters of Albion](https://store.steampowered.com/app/3165650/) (22cans).

## Mods

| Mod | Repository | What it does |
|---|---|---|
| Mod loader | [albion-mod-loader](https://github.com/modded-albion/albion-mod-loader) | A proxy `version.dll` that loads the mod DLLs and mod zips from the `mods` folder of the game. It gives the in-game menu bar and the mod settings. |
| Improved camera | [albion-improved-camera-mod](https://github.com/modded-albion/albion-improved-camera-mod) | The hand controls the camera better: smoother zoom and turn, a free pitch up to a view straight up, and more freedom of movement. |
| Improved sky | [albion-improved-sky-mod](https://github.com/modded-albion/albion-improved-sky-mod) | A real-time moon with the true phase, a night sky with stars, an aurora, and a sky that follows the alignment of the player. |

## Tools

| Tool | Repository | What it does |
|---|---|---|
| Editor | [albion-editor](https://github.com/modded-albion/albion-editor) | A map editor: land, objects, regions, scripts and custom content, exported as mod zips. |

## Install

1. Put `version.dll` from the mod loader next to `moa.exe` in the game folder.
2. Put the mod DLLs and mod zips in the `mods` folder of the game.
3. Start the game. The mods show in the menu bar of the game menu.

Each mod names the game builds that it is for. A Steam update of the game can stop a mod until the mod has a new release.
